Файли сайту (усі мають лежати в корені репозиторію, без вкладених папок):

| Файл | Що це |
|---|---|
| `index.html` | Головна сторінка (лендінг) |

## Як опублікувати на `username.github.io`

1. **Зареєструйтеся на github.com.** Ім’я користувача стане адресою сайту, тому оберіть гарне, наприклад `olgadombrovska` → `olgadombrovska.github.io`.
2. **Створіть репозиторій.** Натисніть **+** (угорі праворуч) → **New repository**.
   - Repository name: **точно** `ваш-username.github.io` (малими літерами).
   - Видимість: **Public**.
   - Натисніть **Create repository**.
3. **Завантажте файли.** На сторінці нового репозиторію натисніть посилання **uploading an existing file**. Перетягніть усі 5 файлів (не папку й не zip!). Унизу натисніть **Commit changes**.
4. **Увімкніть Pages.** Перейдіть у **Settings → Pages**. У блоці *Build and deployment* виберіть Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** і натисніть **Save**. Для репозиторію `username.github.io` це часто вже увімкнено автоматично.
5. **Зачекайте 1–2 хвилини.** На вкладці **Actions** з’явиться процес *pages build and deployment*. Коли він стане зеленим, відкрийте `https://ваш-username.github.io`.
6. **Перевірте:** «Читати онлайн», «Завантажити PDF», вигляд на телефоні. У **Settings → Pages** має стояти галочка **Enforce HTTPS**.

### Для гарного прев’ю в Instagram / Telegram (необов’язково)
В `index.html` знайдіть рядок `<meta property="og:image" content="og.jpg">` і замініть `og.jpg` на повну адресу:
`https://ваш-username.github.io/og.jpg`. Редагувати можна прямо на GitHub: відкрийте файл → іконка олівця → **Commit changes**.

### Як оновити PDF
**Add file → Upload files** → завантажте новий PDF **з тією самою назвою** `investytsii-z-nulia.pdf` → **Commit changes**. Через кілька хвилин на сайті буде нова версія. Якщо бачите стару, оновіть сторінку з очищенням кешу.

### Корисно знати
- Для перегляду PDF використовується бібліотека PDF.js із cdnjs. Тому якщо відкрити `index.html` просто подвійним кліком з комп’ютера, онлайн-читання може не працювати. На GitHub Pages працює все.
- На безкоштовному тарифі GitHub Pages працює лише з публічними репозиторіями. Файли сайту будуть видимі всім, але для публічного гайду це нормально.
